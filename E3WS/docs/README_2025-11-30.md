📌 Resumen Ejecutivo

E3WS es un sistema de alerta sísmica temprana orientado a Latinoamérica.
El objetivo es detectar las ondas sísmicas iniciales (ondas P) y notificar a comunidades, empresas y autoridades en tiempo real antes de la llegada de las ondas destructivas.

Este repositorio contiene la versión más reciente del sitio web institucional, que sirve como interfaz demostrativa del sistema E3WS y de sus capacidades.
